# ☕ Estudos em Java

Repositório dedicado à minha evolução em **Java**, reunindo exercícios, desafios e projetos desenvolvidos durante meus estudos de programação e desenvolvimento Back-End.

O objetivo deste repositório é registrar minha evolução prática, desde os fundamentos da linguagem até conceitos de **Programação Orientada a Objetos**, coleções, herança, polimorfismo, interfaces e projetos maiores.
