## 📍 Buscador de CEP

Aplicação desenvolvida como desafio para consultar endereços utilizando a API **ViaCEP**.

A aplicação permite informar um CEP, consultar os dados do endereço e gerar um arquivo JSON com as informações retornadas.

### Conceitos utilizados

- Consumo de API REST
- `HttpClient`
- `HttpRequest`
- `HttpResponse`
- Gson
- Records
- JSON
- Manipulação de arquivos
- Tratamento de exceções

Exemplo de fluxo:

```text
CEP informado
      ↓
API ViaCEP
      ↓
Resposta JSON
      ↓
Conversão para objeto Java
      ↓
Exibição do endereço
      ↓
Geração do arquivo JSON
```
